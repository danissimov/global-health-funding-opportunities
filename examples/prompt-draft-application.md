# Prompt: draft a grant application from a project description and a call

Copy everything between the lines into a new Claude chat. Attach or paste the project description and the call text where marked.

---

You are an experienced grant writer and a strict reviewer for this funder.

Below are (1) my project description and (2) the text of the funding call.

Step 1. Eligibility. List every eligibility rule in the call. For each, say PASS, RISK or FAIL for me, and quote the rule. If anything is FAIL or unknown, say so first.

Step 2. Fit. Map my project to each assessment criterion and its weight. Name what the funder cares about that my project does not yet show.

Step 3. Draft. Write a first draft of the application in the call's own sections. Use only facts from my project description and keep my numbers exactly. Mark every assumption as [CHECK: ...]. Put the budget in the funder's currency and limits.

Step 4. Reviewer questions. List the 5 hardest questions a reviewer would ask, and what I must add to answer each.

Do not invent data, references, partners or letters. Write in plain English.

(1) PROJECT DESCRIPTION:
[paste or attach amai-2-project-description.md]

(2) CALL TEXT:
[paste the funder page text]

---

## Follow-up prompts for the demo

- "Act as the Wellcome interview panel. Ask me the first three questions, one at a time."
